LtHash

Homomorphic set hashing · ternary SIS · power-of-two collisions

Add and remove items and watch the digest follow by word-wise addition, then cancel the modulus one bit at a time until a set of items hashes to all zeros — with every collision re-hashed from scratch by a checker that never sees the attack.

WHY IT MATTERS

A hash you can update by adding lets one checksum track a database that changes all day, which is why Meta uses Folly’s BLAKE2Xb version for configuration updates. Solana uses BLAKE3 with the same 1,024-word arithmetic. That same linearity is the attack: a 2026 paper cancels two modulus bits per step and reports about 281 hash queries, against the 200 bits of collision security the deployment claimed.
